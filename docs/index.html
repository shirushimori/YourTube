Desktop Installation Guide

To use YourTube on your desktop (Windows/macOS/Linux), follow the automated setup process.

1. Run the automated setup

Make sure you have git and cargo (Rust) installed.

Linux / macOS (Terminal):

curl -sSf https://raw.githubusercontent.com/shirushimori/YourTube/main/install.sh | bash

Windows (PowerShell):

irm https://raw.githubusercontent.com/shirushimori/YourTube/main/install.ps1 | iex

2. Install the Extension

Once the setup script finishes, install the YourTube extension into your browser:

  • Firefox: Download from Mozilla Add-ons
  • Chrome / Brave / Edge: Download the latest yourtube-extension.zip from the GitHub Releases page. Extract it, navigate to chrome://extensions, enable "Developer Mode", and click "Load unpacked" to select the extracted folder.
