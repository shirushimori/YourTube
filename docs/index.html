Desktop Installation Guide

To use YourTube on your desktop (Linux/Windows), follow the automated setup process.

1. Clone the repository

git clone https://github.com/shirushimori/YourTube.git
cd YourTube

2. Run the automated installer

Make sure you have cargo, curl, and zip installed.

./run.sh

3. Load the Extension

The installer creates a yourtube-extension.zip file.

  • Firefox: Go to about:debugging#/runtime/this-firefox, click "Load Temporary Add-on", and select the zip file.
  • Chrome/Edge: Extract the zip, go to chrome://extensions, enable "Developer mode", click "Load unpacked", and select the extracted folder.
